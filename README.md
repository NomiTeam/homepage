# 糯米小镇 · Nomi Town

糯米小镇官网的静态源文件，面向玩家介绍原版生存、种田、钓鱼烹饪、建造与社区生活，并提供入服指引。

- [官网](https://mc.missdrop.cn)
- [加入QQ群](https://qm.qq.com/q/JWCiU0jwyq)
- [NomiTeam GitHub](https://github.com/NomiTeam)

## 入服方式

按QQ群公告获取我们的启动器并完成账号设置，使用我们的启动器启动游戏后自动进入服务器。

## 本地预览

本项目仅使用 HTML、CSS，无构建依赖、无打包步骤。可直接用浏览器打开 `index.html`，也可使用本地静态文件服务器预览。

## 文件与设计

- `index.html`：首页内容、导航与搜索、分享元数据。
- `css/styles.css`：奶油色、暖棕与叶绿的响应式版式，包含键盘焦点样式。
- `img/nomi-logo-*.png`：圆形团子标识，用于导航、页脚及分享图片。
- `img/nomi-mascot-512.png`：透明团子原图，用于首页主视觉。

页面以小镇邀请函为主题，依次呈现品牌、玩法与入住便笺，不依赖外部字体、第三方图片、脚本或在线状态接口。

## 托管

官网使用 EdgeOne makers 静态托管。实际部署分支、触发方式与发布链路以现有托管配置为准。
