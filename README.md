# 糯米小镇 · Nomi Town

糯米小镇官网的静态源文件，提供服务器介绍与入服指南。小镇以 Minecraft 26.3 原版生存、悠闲种田、钓鱼烹饪与社区生活为主题。

- [官网](https://mc.missdrop.cn)
- [加入QQ群](https://qm.qq.com/q/JWCiU0jwyq)：按群公告获取我们的启动器及账号设置说明
- [NomiTeam GitHub](https://github.com/NomiTeam)
- [爱发电](https://afdian.com/a/Missdrop)

## 入服方式

按群公告获取我们的启动器并完成账号设置。使用我们的启动器启动游戏后，会自动进入服务器，无需手动添加。最新客户端要求以群公告为准。

## 本地预览

本项目仅使用 HTML、CSS，无构建依赖、无打包步骤。可直接用浏览器打开 `index.html` 查看页面，也可使用本地静态文件服务器预览。

## 文件与维护

- `index.html`：首页内容、导航与搜索/分享元数据
- `css/styles.css`：响应式布局、颜色与键盘焦点样式
- `img/nomi-logo-*.png`：已确认的团子 Logo，按展示尺寸引用

页面不依赖外部字体、第三方图片或在线状态接口。维护时不要在正文、元数据、脚本、截图或其他对外材料中展示游戏连接地址。

## 托管

官网使用 EdgeOne makers 静态托管。实际部署分支、触发方式与发布链路以现有托管配置为准；提交或推送代码不代表必然上线，发布后仍需回读线上页面确认。
